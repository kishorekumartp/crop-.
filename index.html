    📂
    Data Module
    Ingests CSV datasets (Kaggle Crop Recommendation + Yield datasets). Handles missing values via median imputation. IQR-based outlier removal. LabelEncoder for target classes. StandardScaler for feature normalization.
    🧠
    ML Module
    Dual-model architecture: RandomForestClassifier for crop recommendation (22 classes), GradientBoostingRegressor for yield prediction. 5-fold cross-validation. Ensemble voting optional.
    🌐
    API Module
    Flask REST backend. Validates all inputs before inference. Returns top-5 crops with probabilities + yield in tonnes/ha + agronomic hints. CORS-enabled for frontend integration.

    Project Overview
    🎯
    Problem Statement
    Farmers face critical challenges: selecting the right crop for a given plot, and estimating how much they will harvest. Changing climate patterns, soil variability, and fluctuating fertilizer costs compound the uncertainty. Traditional methods rely on generational knowledge and are not adaptive to data-driven conditions.

    This system uses Artificial Intelligence to analyze 7 key soil and climate features and produce two outputs: (1) a ranked list of suitable crops and (2) a yield estimate in tonnes per hectare.
    🚀
    Future Enhancements
    🛰️ Satellite & remote sensing data integration for NDVI-based field health monitoring
    📱 Mobile application (React Native) for field use without internet connectivity
    🌤️ Real-time weather API integration (OpenWeatherMap) for auto-filled climate inputs
    📡 IoT sensor support — read N/P/K and pH directly from soil probes
    🌍 Multi-language support for regional farmer accessibility

    How It Works
    Weather data is fetched live from OpenWeatherMap API and automatically fills 3 of your 7 predictor inputs:
    ✅ Temperature — current air temp in °C
    ✅ Humidity — relative humidity %
    ✅ Rainfall — IMD annual historical average (mm/year)
    ⌨️ N, P, K — still entered manually
    🧪 Soil pH — from pH sensor or manual entry
